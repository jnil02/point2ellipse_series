# Point-to-ellipse series

Python (reference) and C++ (fast) implementations of the series expansions and
rational coefficients for the point-to-ellipse relation:

**Part I — expansion far from the center:**
Nilsson, J.-O. *Point-to-ellipse Fourier series.*
arXiv: [2507.08807](https://doi.org/10.48550/arXiv.2507.08807) \[math.GM]
The repository includes [the arXiv v1 PDF](2507.08807v1.pdf).
The [LaTeX source](doc/part_I_expansion_about_inf/point2ellipse_series.tex)
contains minor corrections made since that version.

**Part II — expansion about the center (inside-evolute series):**
Nilsson, J.-O. *Point-to-ellipse series -- Part II: Expansion about the center.*
arXiv: [2610.40690](https://doi.org/10.48550/arXiv.2610.40690) \[math.GM]
The repository includes [the arXiv v1 PDF](2610.40690v1.pdf).

The manuscript sources under `doc/` may accumulate corrections independently
of the root-level PDFs; corrected versions may subsequently be submitted to
arXiv. See [the manuscript build instructions](doc/README.md).

## Introduction

The point-to-ellipse relation — the normal direction φ and the signed distance
(height) h from an ellipse to a nearby point — is normally computed by iteration
or by solving the quartic directly. These works instead give general **series
expansions**: Part I valid far from the center, Part II inside the ellipse's
evolute. This repository provides their implementations: exact symbolic
computation of the rational coefficients and evaluation of the truncated series.
For the mathematics, including precise definitions, branch conventions, and
domains of convergence and closest-point validity (with coordinate-axis
exceptions), see the manuscripts.

## Python (reference implementation)

`python/main.py` demonstrates the series by converting a reference
latitude/altitude to Cartesian coordinates and reconstructing the
point-to-ellipse relations from the truncated series (multi-precision).

- `expansions.py`, `expansions_evo.py` — the truncated series expansions
  (far-field / inside-evolute; sin-power form, with Fourier multiple-angle variants).
- `coefficients.py`, `coefficients_evo.py` — the exact rational series
  coefficients (far-field / inside-evolute).
- `polynomials.py`, `series_substitutions.py`, `series.py` — the symbolic
  machinery (potential/Bell polynomials, series arithmetic, substitutions).
- `ellipse.py` — the closed-form (Vermeille) reference and ellipse parameters.
- `symbols.py`, `cache.py`, `util.py` — symbols, memoization, utilities.
- `analysis/` — convergence plots; `tests/` — pytest checks against the
  closed-form reference.

The Python code is a readable reference (practical to ~order 15).

Run the tests from the repository root using your Python environment:

```bash
PYTHONPATH=python python3 -m pytest python/tests
```

`PYTHONPATH=python` makes the reference modules available outside an IDE.

## C++ (fast implementation)

`cpp/` mirrors the Python coefficients and series — checked against the Python
reference via CSV in the tests — but reaches far higher orders. Coefficients are
exact GMP rationals; the series are templated and evaluate either symbolically
(SymEngine) or numerically (`mpfr::mpreal`).

- `coefficients[_evo].{hpp,cpp}`, `expansions[_evo].hpp` — coefficients and series.
- `convergence/` — `sweep_evo`, `diag_coeff_evo`: empirical convergence / region-of-
  convergence studies (CSV output, plotted by `python/analysis`).
- `benchmarks/`, `tests/` — micro-benchmarks and Python-cross-checked tests.

With the C++ code, the practical order is >40.

Build (CMake ≥ 3.15, C++20):

    cmake -S cpp -B cpp/build && cmake --build cpp/build

## Running the C++ tests

The C++ cross-checks read CSV fixtures generated by the Python reference.
These files are not tracked by Git, so generate them before running the tests.
With the Python dependencies installed, run these commands from the repository
root (using your Python environment):

```bash
PYTHONPATH=python python3 python/tests/generate_test_data.py
PYTHONPATH=python python3 python/tests/generate_series_test_data.py
cmake -S cpp -B cpp/build
cmake --build cpp/build
ctest --test-dir cpp/build --output-on-failure
```

The first two commands run the Python generators immediately, writing CSV
files to the repository-root `test_data/` directory for the C++ tests to read.
`PYTHONPATH=python` makes the reference modules available only for that command;
it does not permanently change your environment or configure CMake.

## Dependencies

- **Python reference and fixture generators:** Python 3, SymPy, mpmath.
- **Python tests:** pytest, in addition to the reference dependencies.
- **Python analysis plots:** matplotlib and NumPy, in addition to the reference
  dependencies.
- **C++:** a C++20 compiler, CMake ≥ 3.15, GMP (including its `gmpxx` C++
  interface), MPFR, MPFR C++ (`mpreal.h`), and SymEngine built with MPFR support.
  Install the development headers as well as the libraries. MPFR C++ is a
  separate wrapper; MPFR alone does not provide `mpreal.h`.
- **C++ tests:** Catch2 v2, with its single header available as `<catch.hpp>`
  on the compiler's include path. The current default build includes the tests,
  so this dependency is needed for the build command above.
